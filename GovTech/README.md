# GovTech Project

## Overview
This project focuses on:
- Digital document approval with authentication via smart cards or biometrics.
- Tokenization with P22PP functionality, including Proof-of-Work and reward systems.
- Conversational AI interface for voice interaction.

## Features
1. **Authentication**: Secure approval of documents using smart cards or biometrics.
2. **Tokenization**: Simplified Proof-of-Work for token generation and reward systems.
3. **Conversational AI**: Voice-based interaction for technical environments.

## Setup
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   python main.py
   ```

## Modules
- `authentication`: Handles smart card and biometric authentication.
- `tokenization`: Manages token generation and rewards.
- `voice_interface`: Provides voice-based interaction.
