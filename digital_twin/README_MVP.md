## 🚀 Como Executar

### Windows
```bash
# Instalar dependências
pip install -r requirements.txt

# Executar o MVP
start_aeon_mvp.bat
```

### Linux/Mac
```bash
# Instalar dependências
pip install -r requirements.txt

# Executar o MVP
./start_aeon_mvp.sh
```

### Acesso
- **Frontend:** http://localhost:8000/
- **API Docs:** http://localhost:8000/docs
- **ReDoc:** http://localhost:8000/redoc

## 📊 Funcionalidades MVP

### 1. Dashboard Interativo
- **Métricas em Tempo Real:**
  - Consciência V.E.R.N.A. (0-1)
  - Entropia Shannon (bits)
  - Diferença NMD vs ΛCDM (%)
  - Performance Geral do Sistema

- **Controles de Simulação:**
  - Seletor de tipo de análise
  - Execução de novas simulações
  - Visualização de resultados históricos

### 2. Simulação What-If
- **Parâmetros Ajustáveis em Tempo Real:**
  - Vazão da Turbina (50-120%)
  - Eficiência do Gerador (80-98%)
  - Temperatura da Água (15-35°C)
  - Nível do Reservatório (60-100%)

- **Resultados Instantâneos:**
  - Potência projetada (MW)
  - Ganho de eficiência (%)
  - Impacto na receita (R$ MM/ano)
  - Performance projetada

- **Visualização:**
  - Gráfico de previsão 24h
  - Bandas de incerteza
  - Linha base vs projeção

### 3. Gerador de Relatórios UHE
- **Usinas Suportadas:**
  - Itaipu (14,000 MW)
  - Belo Monte (11,233 MW)
  - Tucuruí (8,370 MW)
  - São Simão (1,710 MW)

- **Tipos de Relatório:**
  - Análise Completa
  - Manutenção Preditiva
  - Análise de ROI
  - Especificações Técnicas

- **Formatos de Saída:**
  - Relatório TXT detalhado
  - Plantas DXF para AutoCAD
  - Downloads automáticos

### 4. Simulação Personalizada
- **Configurações Avançadas:**
  - Tipo de análise (Entropia/V.E.R.N.A./Cosmologia)
  - Número de ciclos de evolução
  - Quantidade de fitas genéticas
  - Taxa de mutação ajustável

- **Resultados Detalhados:**
  - Gráficos personalizados
  - Métricas específicas por tipo
  - Histórico de configurações
