# 🚀 AEON Digital Twin System

## 🎯 Visão Geral

**AEON** é um sistema avançado de **Digital Twin** que combina IA simbólica, rede P2P descentralizada e criptografia enterprise para o setor energético brasileiro.

**🦄 Preparado para ser o próximo UNICÓRNIO brasileiro do setor energético!**

## ✨ Características Principais

- 🎨 **Interface Streamlit** moderna com 7 módulos integrados
- 🧠 **IA Simbólica Emergente** com kernel evolutivo
- 🌐 **Rede P2P** escalável (1.000+ nós testados)
- 🛡️ **VERITAS** - IA + Blockchain + QR Codes
- 🔐 **Crypto Engine** enterprise (RSA-4096 + AES-256)
- 🏭 **Digital Twin** para UHEs e subestações
- 💬 **Chat corporativo** tipo WhatsApp
- 📋 **APR Digital** com assinatura eletrônica

## 🚀 Início Rápido

### Executar Interface Principal
```bash
# Navegar para o projeto
cd aeon_project

# Executar Streamlit (Python 3.10+)
py -m streamlit run aeon_app.py

# Acesso: http://localhost:8501
```

### Verificar Status da Rede
```bash
# Script de diagnóstico
py status_checker.py
```
